# DSA in Java – Part 10: Heaps & Hashing

This repository contains my Java implementations and problem-solving practice focused on **Heaps and Hashing**, two important concepts in Data Structures and Algorithms.

## 📚 Topics Covered

### 1. Heaps
- Introduction to Heap Data Structure
- Min Heap and Max Heap
- Heap Implementation
- Insertion in Heap
- Deletion in Heap
- Heapify Algorithm
- Heap Sort
- Priority Queue
- Problems Based on Heaps

### 2. Hashing
- Introduction to Hashing
- Hash Functions
- HashMap in Java
- HashSet in Java
- Frequency Counting
- Duplicate Detection
- Hashing-Based Searching
- Problems Based on Hashing

## 🛠️ Technologies Used

- **Language:** Java
- **IDE:** VS Code
- **Concepts:** Heap, Priority Queue, HashMap, HashSet, Java Collections Framework

## 🎯 Learning Objectives

- Understand Min Heap and Max Heap operations.
- Learn heap insertion, deletion, and heapify techniques.
- Understand hashing and hash-based data structures.
- Practice using HashMap and HashSet in Java.
- Improve problem-solving skills and algorithmic thinking.
